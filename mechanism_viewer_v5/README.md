# mechanism_viewer_v5

**机制查看器 v5** — 对应 **`reflection_v5`**（系列第06篇 · Reflection 质检）。

版本下拉含 v1～v4 全条目；第06篇（Reflection）仅 **自洽性 / 批评与精炼 / 思维树+批评精炼** 三项。右侧新增 **质检与修订** 标签页。CoT、ToT 等推理模式请选第05篇 v4 条目。

```powershell
$env:ZHIPU_API_KEY="你的Key"
cd mechanism_viewer_v5
pip install -r requirements.txt
python mechanism_client.py
```

或双击 `启动机制查看器.bat`。
