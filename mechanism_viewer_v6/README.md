# mechanism_viewer_v6

**机制查看器 v6** — 对应 **`react_v6`**（系列第 07 篇 · 商用 Agent 一体化运行机制）。

默认版本 **`v6_commercial`**；**运行轨迹** Tab 展示本轮自动选角、计划比选、批评精炼与 ReAct 工具链。

## 启动

```powershell
cd agent_lab/mechanism_viewer_v6
pip install -r requirements.txt
python mechanism_client.py
```

或双击 `启动机制查看器.bat`。

前六篇机制对照仍可用 `mechanism_viewer_v2`～`v5`。
